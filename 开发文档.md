前端改造策略（渐进式迁移）
核心思路是改造 Storage 对象，使其成为一个代理层，同时支持 localStorage 和后端 API：

// shared/js/storage.js — 改造思路
const Storage = {
    // Add backend mode flag
    useBackend: false,
    token: null,
    API_BASE: 'http://localhost:8000/api',

    // Example: getDietByDate becomes
    async getDietByDate(date) {
        if (this.useBackend && this.token) {
            const res = await fetch(`${this.API_BASE}/diet/${date}`, {
                headers: { 'Authorization': `Bearer ${this.token}` }
            });
            return res.json();
        }
        // Fallback to localStorage
        const records = this.getDietRecords();
        return records[date] || { date, dayType: 'training', foods: [], totals: {...} };
    },
    // ... other methods similarly wrapped
}; 
注意：因为当前前端全是同步调用 Storage.xxx()，切换为后端 API 后需要改为 await Storage.xxx()，这意味着调用方也需要改为 async/await。建议分阶段迁移。

迁移步骤建议
第一阶段：搭建后端基础 — 创建 FastAPI 项目、数据库模型、认证模块

第二阶段：实现核心 API — 饮食、训练、体重的 CRUD 接口

第三阶段：AI 代理迁移 — 把 DeepSeek API Key 从前端移到后端（安全性提升）

第四阶段：前端改造 — 改造 Storage 为 async 代理层，逐模块切换

第五阶段：登录注册 — 实现完整的用户认证 UI 和数据隔离

你想让我从哪个阶段开始实现？我建议从第一阶段开始：搭建 FastAPI 后端项目骨架 + 数据库模型 + 认证模块。

### 2.3 Engine & Session 配置

```python
# backend/app/database.py
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine

engine = create_async_engine(settings.DATABASE_URL, echo=False)
async_session = async_sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)
```

- **异步引擎**：使用 `create_async_engine`，全程异步操作
- **Session 依赖注入**：通过 `get_db()` generator 向 FastAPI 路由提供数据库会话

## 七、ORM Model 编写规范

### 7.1 基类

所有模型继承自 `app.database.Base`（`DeclarativeBase`）：

```python
from app.database import Base

class MyModel(Base):
    __tablename__ = "my_table"
    ...
```

### 7.2 字段声明风格

使用 SQLAlchemy 2.0 `Mapped` 类型注解风格：

```python
from sqlalchemy.orm import Mapped, mapped_column
from sqlalchemy import String, Integer, Float, DateTime, ForeignKey, JSON, func

# 主键
id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)

# 外键 + 索引
user_id: Mapped[int] = mapped_column(ForeignKey("users.id"), nullable=False, index=True)

# 字符串字段
name: Mapped[str] = mapped_column(String(200), nullable=False)

# 可选字段
duration: Mapped[int | None] = mapped_column(Integer, nullable=True)

# JSON 字段
plan_data: Mapped[dict | None] = mapped_column(JSON, nullable=True)

# 时间戳（自动填充）
created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())
updated_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now(), onupdate=func.now())
```

### 7.3 关联关系声明

```python
from sqlalchemy.orm import relationship

# 一对多（父端）
foods: Mapped[list["Food"]] = relationship(back_populates="diet_record", cascade="all, delete-orphan")

# 多对一（子端）
diet_record: Mapped["DietRecord"] = relationship(back_populates="foods")

# 一对一
settings: Mapped["UserSettings"] = relationship(back_populates="user", uselist=False, cascade="all, delete-orphan")
```

### 7.4 防止循环导入

使用 `TYPE_CHECKING` 保护导入：

```python
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from app.models.user import User
```

### 8.2 查询

```python
from sqlalchemy import select

# 按条件查询单条
stmt = select(DietRecord).where(
    DietRecord.user_id == user_id,
    DietRecord.date == date
)
result = await db.execute(stmt)
record = result.scalar_one_or_none()

# 查询列表（带排序、限制）
stmt = select(WeightRecord).where(
    WeightRecord.user_id == user_id

records = result.scalars().all()
```
